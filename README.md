# Digit Object Detection Using Deep Learning

## Project Overview
This project explores digit object detection using deep learning and computer vision. The Jupyter Notebook contains the implementation, model training, and evaluation steps.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Jupyter Notebook

## Project File
- `Object_Detection.ipynb` — Notebook containing the project implementation.

## Objective
To explore how deep learning can be used to identify and locate digits in images.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open `Object_Detection.ipynb` in Jupyter Notebook or Google Colab.
4. Run the notebook cells in order.
